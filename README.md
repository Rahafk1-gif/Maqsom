# مقسوم — التاجر يقسّم أرباحه ويضمنها

موقع كامل بتسجيل دخول حقيقي وقاعدة بيانات (Next.js + Supabase).

## الصفحات
- الرئيسية: التعريف بالمنصة
- إنشاء حساب / تسجيل دخول
- لوحة التحكم: حاسبة صافي الربح، محفوظة لكل تاجر في قاعدة البيانات

## التقنيات
- Next.js 14
- Supabase (قاعدة بيانات + تسجيل دخول)
- Vercel (استضافة)
